# curl_cffi 0.16.3 vs curl_reap: API and behaviour parity checklist

Goal: make curl_reap a drop-in superset of curl_cffi.requests. Every row cites the code that defines the behaviour.

## Scope and legend

- curl_cffi_version: 0.16.3 (libcurl-impersonate 2.2.2 bundled; installed wheel tag cp310-abi3-macosx_11_0_arm64; _wrapper.abi3.so 6495776 bytes)
- curl_reap_version: 1.1.0 on branch feat/beyond-curl-cffi
- python: 3.12.12, OpenSSL 3.6.5, hyper-h2 4.4.1, cryptography 50.0.2
- path_legend: curl_cffi/... is relative to .venv/lib/python3.12/site-packages/; curl_reap/... is relative to the repository root; h2/... is the installed hyper-h2 package
- status_legend: have = equivalent behaviour exists; partial = exists with different name, type, default or coverage; missing = no equivalent
- evidence_scripts: scratchpad/api-parity/scripts/echo_http.py (raw request heads over plain http), redirects.py (cross-host redirect lab), throughput.py (64 MiB local download), mem.py (RSS per Session)

## Totals

- checklist rows: 110 (have 15, partial 49, missing 46)
- curl_cffi weaknesses with evidence: 11

## Headline gaps, in the order an implementer should close them

1. TLS ClientHello control (JA3/JA4) and HTTP/2 SETTINGS/pseudo-header order: the only layers where curl_cffi is measurably ahead; needs a Python TLS 1.3 client on cryptography primitives and an H2Spec driving hyper-h2.
2. Request API surface: stream=True with iter_content/iter_lines, content=, files=/multipart=, cookies= per request, proxies dict and socks/https proxies, tuple timeouts, quote, referer, accept_encoding, content_callback, default_headers, cert, interface, doh_url, max_recv_speed, discard_cookies, raise_for_status, response_class, base_url, session params/auth/cookies.
3. Response surface: lazy text, reason, ok as 200-399, multi-value Headers, Cookies mapping, timedelta elapsed, charset aliases, redirect_count/redirect_url/is_redirect, http_version, peer/local addresses, byte counters, request snapshot, close/aclose.
4. Exception hierarchy with curl error codes (RequestsError alias, Timeout, SSLError, DNSError, ProxyError, TooManyRedirects, HTTPError, IncompleteRead...).
5. WebSocket and AsyncWebSocket (entirely absent).
6. Names: 42 curl_reap targets do not match the 42 curl_cffi 0.16.3 names and aliases; header sets lag (chrome131 Windows vs chrome150 macOS, Accept-Encoding without br/zstd).
7. Compatibility shims: RetryStrategy, CacheBackend/FileCacheBackend, cache=int|timedelta, module-level request/put/patch/delete/head/options, Session.patch/options/trace/query, AsyncSession max_clients/upkeep.

## Checklist

### module functions

#### curl_cffi.requests.request(method, url, thread=None, curl_options=None, debug=None, **kwargs)

- status: **partial**
- curl_cffi semantics: Builds a throwaway Session(thread=, curl_options=, debug=) for every call and delegates to Session.request, so module-level calls never reuse connections or cookies (curl_cffi/requests/__init__.py:76-145).
- curl_reap today: curl_reap/http.py:1565-1593 (shared keep-alive module session; get/post/fetch/download only)
- gap: No module-level request(); thread/curl_options/debug keywords unknown.
- minimal change for parity: Add request(method, url, **kw) on the package delegating to the shared session; accept thread=, curl_options=, debug= and warn that they are libcurl-only no-ops.

#### get/post/put/patch/delete/head/options/trace/query

- status: **partial**
- curl_cffi semantics: Thin wrappers calling request(method=...) (curl_cffi/requests/__init__.py:148-181); QUERY and TRACE are first-class methods (session.py:177-179).
- curl_reap today: curl_reap/http.py:1578-1593 (get, post, fetch, download); Session has get/post/head/put/delete at 1528-1541; AsyncSession has get/post/head at curl_reap/aio.py:48-55
- gap: Missing module-level put/patch/delete/head/options/trace/query; Session lacks patch/options/trace/query; AsyncSession lacks put/patch/delete/options/trace/query.
- minimal change for parity: Add the missing one-line wrappers on the module, Session and AsyncSession.

### Session constructor

#### Session(curl=None, thread=None, use_thread_local_curl=True, **BaseSessionParams)

- status: **partial**
- curl_cffi semantics: First positional is a Curl handle; a fresh Curl is created per thread through threading.local (curl_cffi/requests/session.py:485-577); thread= selects eventlet/gevent perform (816-827); context manager closes the current thread's handle (585-594).
- curl_reap today: curl_reap/http.py:1342-1393 (Session(profile='chrome', headers, timeout, retries, proxy, rotate, profiles, retry_policy, cache, on_response, block_rotations, verify, allow_redirects, max_redirects, impersonate, http2, sticky, url_policy))
- gap: First positional is profile, not curl; curl/thread/use_thread_local_curl unknown; several curl_cffi keywords (listed in the rows below) raise TypeError today.
- minimal change for parity: Keep profile first but make every curl_cffi BaseSessionParams keyword accepted; accept curl=, thread=, use_thread_local_curl= and ignore them with a one-time warning.

#### headers

- status: **have**
- curl_cffi semantics: Wrapped in Headers and stored as session.headers; per-request headers override by key; both are rendered into CURLOPT_HTTPHEADER in insertion order (session.py:258, 721; curl_cffi/requests/utils.py:716-760).
- curl_reap today: curl_reap/http.py:1368 (tuple of validated pairs), 1443 (_merge_headers), 169-186 (case-insensitive last-wins merge keeping position)
- gap: session.headers is a private immutable tuple (_headers), not a mutable mapping.
- minimal change for parity: Expose Session.headers as the new Headers mapping (see Headers row) and read it at request time.

#### cookies

- status: **partial**
- curl_cffi semantics: Cookies(cookies) accepts dict, list of pairs, http.cookiejar.CookieJar or Cookies; the cookies property setter re-wraps assignments (session.py:259, 471-478; curl_cffi/requests/cookies.py:136-151).
- curl_reap today: curl_reap/http.py:1369 (self.cookies = CookieJar()), 514-626 (CookieJar)
- gap: No cookies= constructor argument; no dict/CookieJar input; assignment to session.cookies is not validated.
- minimal change for parity: Add cookies= seeding the jar (dict/list -> host-less cookies applied to every request host like curl_cffi's _eff_request_host, CookieJar -> imported) and a property setter.

#### auth

- status: **missing**
- curl_cffi semantics: Session default (username, password) used when the request passes none (session.py:260, 724); rendered as CURLOPT_USERNAME/PASSWORD which libcurl sends as HTTP Basic (utils.py:798-802).
- curl_reap today: curl_reap/http.py:1434 (per-request auth only)
- gap: No session-level auth.
- minimal change for parity: Store auth on the Session and use it as the request default.

#### proxies / proxy / proxy_auth

- status: **partial**
- curl_cffi semantics: proxies is a dict keyed by 'all', 'http', 'https', 'ws', 'wss' or 'scheme://host' / 'all://host'; proxy is shorthand for {'all': proxy}; passing both raises TypeError (session.py:295-300; utils.py:838-863). Resolution order per request: proxies[scheme] else proxies['all'], then an exact 'scheme://host' or 'all://host' entry wins. proxy_auth tuple becomes PROXYUSERNAME/PROXYPASSWORD (utils.py:882-885).
- curl_reap today: curl_reap/http.py:1376-1393 (proxy str or rotation list), 727-734 (credentials parsed from proxy URL userinfo)
- gap: No proxies dict, no per-scheme or per-host mapping, no proxy_auth tuple; proxy+rotation is a curl_reap-only superset.
- minimal change for parity: Accept proxies= with the same key lookup order and proxy_auth=; keep list rotation.

#### base_url

- status: **missing**

- curl_reap today: n/a
- gap: No base_url.
- minimal change for parity: Add base_url with the same validation and urljoin step before params are applied.

#### params

- status: **missing**

- curl_reap today: curl_reap/http.py:1444 (request-level params only)
- gap: No session-level params.

#### verify

- status: **have**
- curl_cffi semantics: True/False/CA-bundle path; when True or None the REQUESTS_CA_BUNDLE or CURL_CA_BUNDLE env var replaces it (session.py:308-313); False sets SSL_VERIFYPEER=0 and SSL_VERIFYHOST=0; a str sets CAINFO and PROXY_CAINFO (utils.py:887-903). Default CA file comes from SSL_CERT_FILE/CURL_CA_BUNDLE/REQUESTS_CA_BUNDLE, then Python's default verify paths, then certifi (curl_cffi/curl.py:22-38).
- curl_reap today: curl_reap/http.py:1365, 1433; curl_reap/tls.py:268-272 (ssl.create_default_context(cafile=...), CERT_NONE when False)
- gap: No env-var override; no certifi fallback (system store only).
- minimal change for parity: Honour REQUESTS_CA_BUNDLE/CURL_CA_BUNDLE/SSL_CERT_FILE when verify is True; optional certifi fallback when the system store is empty.

#### timeout

- status: **partial**
- curl_cffi semantics: float seconds (default 30) or (connect, read) tuple; None disables timeouts. Non-stream: TIMEOUT_MS = whole transfer, tuple collapses to CONNECTTIMEOUT_MS + TIMEOUT_MS(connect+read). Stream: CONNECTTIMEOUT_MS plus LOW_SPEED_LIMIT=1 byte/s over LOW_SPEED_TIME=ceil(seconds) as an inactivity timeout (utils.py:804-825; session.py:234, 725).
- curl_reap today: curl_reap/http.py:1360, 1420, 684-687 (one float used as connect timeout and per-recv socket timeout)
- gap: Tuple raises TypeError ('tuple' object cannot be interpreted as an integer, observed); None means blocking forever (same as curl_cffi); curl_reap's float is per socket operation, curl_cffi's is whole-transfer.
- minimal change for parity: Accept (connect, read): connect for create_connection, read as settimeout afterwards; optionally add a total deadline to mirror TIMEOUT_MS.

#### trust_env

- status: **missing**
- curl_cffi semantics: Accepted and stored (session.py:235, 265) but never read by set_curl_options; libcurl's own http_proxy/https_proxy/no_proxy env handling stays active regardless (only references: session.py:102, 235, 265, 515, 1006).
- curl_reap today: no environ/getproxies reference in curl_reap/http.py, aio.py, tls.py (grep)
- gap: curl_reap never reads proxy or CA env vars; curl_cffi's flag is a no-op but libcurl reads env proxies.
- minimal change for parity: Add trust_env=True reading http_proxy/https_proxy/all_proxy/no_proxy via urllib.request.getproxies() when no explicit proxy is given, and make False actually disable it (which exceeds curl_cffi).

#### allow_redirects

- status: **partial**
- curl_cffi semantics: bool, CurlFollow enum (ALL=1, OBEYCODE=2, FIRSTONLY=3, SAFE=4) or the string 'safe'; SAFE rejects redirects to private/internal IPs (SSRF guard) inside curl-impersonate (session.py:236; utils.py:827-833; curl_cffi/const.py:632-647).
- curl_reap today: curl_reap/http.py:1366, 1064 (bool); 1043-1044 and 1334-1340 (url_policy callable checked on every hop)
- gap: No CurlFollow/'safe' values; OBEYCODE/FIRSTONLY semantics for custom methods absent.
- minimal change for parity: Map 'safe'/CurlFollow.SAFE to a built-in private-IP-rejecting url_policy (resolve the host, refuse RFC1918/loopback/link-local); implement OBEYCODE (reset custom method on 301/302/303) and FIRSTONLY (reset on any hop).

#### max_redirects

- status: **partial**
- curl_cffi semantics: Default 30; -1 means unlimited; exceeding raises TooManyRedirects (CurlECode 47) carrying the last 3xx as .response (session.py:237; utils.py:836; observed: curl_cffi.requests.exceptions.TooManyRedirects code 47 response <Response [302]>).
- curl_reap today: curl_reap/http.py:1345 (default 10), 1067-1068 (raises TransportError('too many redirects (maximum N)'))
- gap: Default 10 not 30; -1 not supported; error type is TransportError without the last response.
- minimal change for parity: Default 30, treat -1 as unlimited, raise a TooManyRedirects(RequestException) subclass with .response set to the last hop.

#### retry

- status: **partial**
- curl_cffi semantics: int or RetryStrategy(count, delay=0.0, jitter=0.0, backoff='linear'|'exponential'); validated (>=0) at construction; the request loop retries only when a RequestException propagates (not on HTTP status codes); delay = delay*attempt (linear) or delay*2^(attempt-1) (exponential) plus uniform(0, jitter); seekable bodies are rewound, non-rewindable iterators raise UnrewindableBodyError (session.py:191-216, 461-469, 893-943; curl_cffi/requests/streams.py:42-69).
- curl_reap today: curl_reap/http.py:69-109 (RetryPolicy(retries=2, backoff=0.5, max_backoff=30, statuses, respect_retry_after, allowed_methods)), 1414-1419 (per-request retries/retry_policy), 1485-1518 (retries transport errors and listed statuses, honours Retry-After, idempotent-method guard)
- gap: Keyword is retries/retry_policy not retry; no RetryStrategy class; curl_reap retries 408/425/429/5xx by default while curl_cffi retries nothing by default; curl_reap jitter is multiplicative (0.5x-1.5x) not additive.
- minimal change for parity: Accept retry=int|RetryStrategy as an alias (count->retries, delay/backoff/jitter mapped, statuses=() to match curl_cffi semantics) and export RetryStrategy from curl_reap.

#### impersonate

Sets TLS ClientHello, HTTP/2 SETTINGS and pseudo-header order, header set and order.
- curl_reap today: curl_reap/http.py:1349-1352 (impersonate aliases profile), 1426-1432 (per request); curl_reap/tls.py:178-256 (42 targets: chrome98..chrome133, edge126..edge133, firefox95..firefox135, safari15_3..safari18_0, aliases chrome=chrome131, edge=edge131, firefox=firefox135, safari=safari18_0)

- minimal change for parity: Register every curl_cffi 0.16.3 name with the same alias map (keep old curl_reap names as aliases), copy each target's exact header set from curl_cffi output, and attach TLS and HTTP/2 specs per target (see the fingerprint fidelity rows).

### AsyncSession constructor

### request() parameters

#### method

- status: **have**
- curl_cffi semantics: Upper-cased; POST without a streaming body uses CURLOPT_POST, every other non-GET method uses CUSTOMREQUEST, HEAD sets NOBODY; GET with a body sends it with CUSTOMREQUEST GET (utils.py:635, 676-682, 702-713).

- gap: none material
- minimal change for parity: none

#### url + quote

- status: **partial**
- curl_cffi semantics: After params and base_url: quote='' (default) runs requote_uri (unquote unreserved %XX, re-quote illegal chars, keep reserved and %); quote='abc' additionally percent-encodes those characters in path and query via quote_path_and_params (safe set '!#$%&'()*+,/:;=?@[]~' minus the given chars); quote=False leaves the URL byte-exact (utils.py:48, 95-107, 165-213, 692-696).
- curl_reap today: curl_reap/http.py:204-207 (_request_target quotes path with safe '/%:@!$&'()*+,;=-._~' and query with safe '=&?/:;+,%@!$'()*-._~')
- gap: No quote= parameter; cannot force extra encoding or disable normalisation; existing %XX are kept (same as requote) but unreserved escapes are not unquoted.
- minimal change for parity: Port requote_uri/unquote_unreserved and quote_path_and_params; add quote=''|str|False with identical behaviour.

#### params

- status: **partial**
- curl_cffi semantics: dict, list or tuple of pairs; a key that occurs exactly once in both the URL and params is replaced in place, otherwise appended; bool and dict values are json.dumps-encoded ('flag=true', 'd=%7B%22k%22%3A+1%7D'); lists expand with doseq (utils.py:110-162; observed 'http://h/p?a=2&flag=true&d=%7B%22k%22%3A+1%7D&l=x&l=y').
- curl_reap today: curl_reap/http.py:210-216 (_url_with_params appends urlencode(params, doseq=True) to the existing query)
- gap: Duplicates kept ('a=1&a=2'), bool renders 'True', dict renders its keys only (observed 'http://h/p?a=1&a=2&flag=True&d=k&l=x&l=y').
- minimal change for parity: Replace _url_with_params with curl_cffi's update_url_params semantics (1:1 key replacement, json encoding of bool/dict).

## curl_cffi weaknesses curl_reap can turn into advantages

1. **Every plain-http request carries a libcurl tell that no browser sends: 'Upgrade: h2c', 'HTTP2-Settings: <base64url>' and 'Connection: Upgrade, HTTP2-Settings'.**
   Evidence: echo_http.py against a local raw-socket echo server: curl_cffi get(url, impersonate='chrome') produced 'Upgrade: h2c', 'HTTP2-Settings: AAEAAQAAAAIAAAAAAAQAYAAAAAYABAAA' (decodes to SETTINGS 1:65536,2:0,4:6291456,6:262144) and 'Connection: Upgrade, HTTP2-Settings'; firefox decoded to 1:65536,2:0,4:131072,5:16384 and safari to 2:0,3:100,4:2097152,9:1; even impersonate=None sent them. curl_reap's request for the same URL had no Upgrade/HTTP2-Settings/Connection headers (curl_reap/http.py:962-971). Cause: fingerprints default http_version 'v2' (curl_cffi/fingerprints.py:374) and libcurl upgrades over cleartext unless http_version is forced.

2. **Binary-only distribution: 21 wheels per release, 1.7 MB to 13.5 MB each, 179 MB total, Python 3.10+ only, and whole platforms with no wheel and no buildable sdist.**
   Evidence: https://pypi.org/pypi/curl_cffi/json for 0.16.3: cp310-abi3 wheels for macosx_10_9_x86_64 (3,025,646 B), macosx_11_0_arm64 (2,784,023), manylinux2014 aarch64/i686/x86_64 (12.8-13.5 MB), manylinux_2_28 armv7l, manylinux_2_34 riscv64, musllinux_1_2 aarch64/x86_64, win_amd64 (1,978,602), win_arm64 (1,713,140); cp313/cp314 android_24_arm64_v8a; cp314t free-threaded wheels; sdist 239,020 B; requires_python >=3.10; total 179,028,360 B. Installed _wrapper.abi3.so is 6,495,776 B. No wheels for: win32 (32-bit Windows), Linux ppc64le, s390x, loongarch64, musllinux i686/armv7l/riscv64, Android x86_64, PyPy (only cp310-abi3/cp313/cp314 tags), Python 3.9 or older, iOS, Emscripten/Pyodide, FreeBSD/OpenBSD/NetBSD/illumos/AIX. The sdist cannot compile on those either: scripts/build.py downloads a prebuilt libcurl-impersonate v2.2.2 tarball from GitHub releases (build.py:105-125) for the fixed system/machine/libc list in libs.json (Windows AMD64 64/32 and ARM64; Darwin x86_64/arm64; Linux x86_64 gnu/musl, i686 gnu, aarch64 gnu/musl, riscv64 gnu, armv6l/armv7l gnueabihf, loongarch64 gnu; Android aarch64) and raises 'Unsupported arch' otherwise (build.py:64). curl_reap is a pure-Python hatchling package (pyproject.toml: packages=['curl_reap'], requires-python >=3.9) whose only binary dependency is lxml, which ships wheels for far more targets and builds from source against libxml2.

3. **No HTML parser or extraction layer; the one convenience method, Response.markdown(), crashes with NameError unless optional extras are installed.**
   Evidence: grep for css/xpath/lxml/Selector across curl_cffi/*.py and curl_cffi/requests/*.py matches nothing but asyncio selector code; models.py:23-25 wraps 'from markdownify import markdownify' and 'import readability' in suppress(ImportError), and models.py:225-230 uses rd.Document, so calling markdown() in this venv raised NameError: name 'rd' is not defined (observed). curl_reap ships Selector with css/xpath/jsonld/links/images/tables/markdown/extract on every Response (curl_reap/http.py:1254-1303; curl_reap/parser.py).

4. **No crawl engine, scheduler, throttling, robots handling, pipelines, rotation or proxy block handling; curl_cffi is a transport only.**
   Evidence: Package contents: aio.py, curl.py, const.py, fingerprints.py, requests/ (session, models, cookies, headers, cache, streams, websockets, exceptions, impersonate, utils), cli/; no spider, scheduler, robots or pipeline modules. curl_reap has Spider/SitemapSpider/Request (spider.py), Reaper/run (engine.py), AutoThrottle (throttle.py), pipelines (pipelines.py), per-session proxy and profile rotation with block-driven rotation on 403/407/429 (curl_reap/http.py:1399-1408, 1508-1513) and retries with Retry-After (69-109).

5. **Thread safety is achieved by duplicating a libcurl handle per thread, and cleanup is incomplete: close() only closes the calling thread's handle and the streaming executor is never shut down.**
   Evidence: Session stores a Curl per thread in threading.local and creates one lazily in any new thread (curl_cffi/requests/session.py:553-577); close() does self.curl.close() only (591-594), so handles created by other threads live until the thread-local is garbage collected; the ThreadPoolExecutor created for stream=True (579-583, used at 790) has no shutdown call anywhere in session.py (grep 'shutdown' returns nothing); using a user-supplied curl from another thread only warns (566-572). curl_reap uses one lock-protected pool, one lock-protected jar and a counter lock shared by all threads (curl_reap/http.py:629-741, 514-626, 1373-1374) and close() closes every pooled connection (1088-1094).

6. **The perform model re-enters Python for every received buffer, streams with no backpressure, needs a thread per in-flight stream, and the async session polls every 100 ms for its whole life.**
   Evidence: Each request is one blocking lib.curl_easy_perform (curl_cffi/curl.py:588); libcurl calls buffer_callback/write_callback per buffer, which copies the data with ffi.buffer(ptr, nmemb)[:] and re-acquires the GIL (curl.py:163-168, 177-189). In stream mode the queue is created with no maxsize and fed with put_nowait (curl_cffi/requests/utils.py:1001-1011), so a slow consumer accumulates the entire body in memory; each streamed response occupies an executor thread until done (session.py:790). AsyncCurl runs _force_timeout, a loop calling socket_action then asyncio.sleep(0.1) forever until close (curl_cffi/aio.py:228-235), and AsyncSession serialises requests beyond max_clients=10 (session.py:981, 1068-1084). Raw throughput is not the weakness: on a local 64 MiB download curl_cffi took 0.019 s buffered / 0.026 s streamed versus curl_reap 0.512 s buffered / 0.079 s to disk (throughput.py); the curl_reap buffered number is dominated by eager text decoding (curl_reap/http.py:379-383, 1166-1181), which the checklist flags separately.

7. **Each Session or Curl handle costs about 31-33 KiB of resident memory before any request, roughly 60x curl_reap's Session, because every Curl pre-allocates WebSocket buffers it may never use.**
   Evidence: mem.py (200 objects, ru_maxrss delta): curl_cffi Session() 33.0 KiB each, Curl() 31.0 KiB each, curl_reap Session() 0.5 KiB each; import time 82 ms (curl_cffi.requests) vs 59 ms (curl_reap). Curl.__init__ allocates a 128 KiB char[] receive buffer plus size_t/frame pointers and a 256-byte error buffer unconditionally (curl_cffi/curl.py:264, 289, 294-297); AsyncSession may hold up to max_clients such handles (session.py:1076-1084).

8. **New fingerprints depend on a commercial API and a new binary release: non-native targets are fetched from api.impersonate.pro with an API key, and native targets are frozen into the compiled library.**
   Evidence: DEFAULT_API_ROOT = 'https://api.impersonate.pro/v1' (curl_cffi/fingerprints.py:341); get_api_key reads IMPERSONATE_API_KEY or config.json (466-480); update_fingerprints sends Authorization: Bearer <key> (534-541); load_fingerprints merges NATIVE_IMPERSONATE_TARGETS with ~/.config fingerprints.json (629-639); the CLI exposes update/list/config --api-key (cli/pro.py:66-100). curl_reap profiles are plain Python data (curl_reap/tls.py:178-221) editable in place.

9. **The ja3/akamai/extra_fp escape hatches are narrower than they look: TLS 1.2-only JA3, hard asserts, KeyErrors, and a mistyped form_boundary.**
   Evidence: set_ja3_options asserts the version is TLS 1.2 ('Only TLS v1.2 works for now', utils.py:264) and that point formats == 0 (296); unknown cipher ids raise ImpersonateError (269-271) and unknown curve ids raise a bare KeyError (291); a padding extension is silently removed with a warning (276-284). ExtraFingerprints.form_boundary is typed Optional[bool] (curl_cffi/requests/impersonate.py:191) while Fingerprint.form_boundary is a str (fingerprints.py:399) and CURLOPT FORM_BOUNDARY receives it verbatim (utils.py:357-358).

10. **Several documented request features are unimplemented or inconsistent in 0.16.3 and can be confirmed from the code without a network.**
   Evidence: files= raises NotImplementedError (utils.py:784-789; observed); iter_content/aiter_content ignore chunk_size with a warning and raise NotImplementedError for decode_unicode (models.py:278-285, 361-368); AsyncSession(cache=...) raises NotImplementedError (session.py:1042-1046); a (connect, read) timeout is converted to a single whole-transfer timeout of connect+read (utils.py:808-813) and to an integer-second low-speed timeout in stream mode (814-825); trust_env is stored but never read (session.py:235, 265 only) so trust_env=False does not stop libcurl reading http_proxy; module-level get()/post() construct a new Session per call so there is no keep-alive between calls (requests/__init__.py:143-145); request()'s accept_encoding default 'gzip, deflate, br' (session.py:686, 870) disagrees with set_curl_options' 'gzip, deflate, br, zstd' (utils.py:613) and is overridden by the fingerprint header anyway (observed); streamed connections are never pooled because the duplicated handle is closed (session.py:707-708; models.py:327-328); CacheBackend has no ETag/If-Modified-Since revalidation (cache.py:120-135) whereas curl_reap revalidates (curl_reap/http.py:1462-1507).

11. **Edge-case behaviours that bite scrapers, reproduced in this venv.**
   Evidence: Cross-host redirect after POST forwards a stale 'Content-Type: application/octet-stream' and 'Proxy-Authorization' to the new host (redirects.py output for 301/302/303); update_url_params JSON-encodes booleans and dicts so params={'flag': True} becomes 'flag=true' and a dict becomes an encoded JSON blob (utils.py:137-139; observed); Headers.items()/values() render None values as the string 'None' (headers.py:168, 183; observed); Cookies.get()/__getitem__ raise CookieConflict when a name exists on two unrelated domains (cookies.py:302-313; observed), so response.cookies['x'] can raise; a bare Response() reports status_code 200, ok True, reason 'OK' (models.py:112-114; observed); code2error classifies proxy failures by the substring 'CONNECT' in the error text (exceptions.py:224-227).
